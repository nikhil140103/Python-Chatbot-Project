# Python-Chatbot-Project
A Python based chatbot project that provides company related information using JSON data. The chatbot can answer basic user queries and simulate a virtual company assistant through simple interactive responses.


# Chatbot

This is a chatbot made using Python.

The chatbot answers questions based on a dataset of around 40 questions and answers.
The questions and answerss are stored in a JSON file.
And this chatbot based on company enquiry..

The chatbot uses basic NLP concepts like TF-IDF and cosine similarity to find the closest question from the dataset and return the correct answer.

Files in this project:

chatbot.py = main chatbot code
data.json = dataset containing questions and answers
README.md = project information

How to run code:

Install required library: pip install scikit-learn

Run the chatbot:  python chatbot.py

After running the program, you can type questions in the terminal to better reply.
Start the conversation to chatbot saying Hello
Type exit or bye to stop the chatbot.

Example questions:

What is your company name?
Do you provide internships?
What technologies do you use?
